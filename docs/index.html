Structural bioinformatics · Python · PyMOL

Watch proteins move using structures that already exist.

The simulator collects experimental structures of a protein from the PDB, fits them onto each other and plays them as one animation. You see the conformational change without running a molecular dynamics simulation.

Get started View on GitHub

From a PDB code to an animation in five steps

Each animation frame is either a real deposited structure or a linear interpolation between two of them, so this is a pseudo-dynamics method. Any step can be skipped by supplying its result, which avoids repeating the slow network queries.

  1. Fetch the sequence

    The PDB code is searched in NCBI Entrez and the FASTA sequence of the first matching protein record is downloaded.

    Entrez-id

  2. Find related structures

    BLASTp against the PDB keeps hits with ≥ 99 % identity and E ≤ 0.05. Near-identity means the differences are conformational, not evolutionary.

    BLASTpskip: -al / -l

  3. Download mmCIF

    Each hit is downloaded with Biopython PDBList into pdbs/. Files already present are reused.

    Biopython

  4. Filter and map chains

    Structures with fewer than half or more than twice the reference's atoms are dropped. Chain IDs are translated from label_asym_id to the author IDs.

    0.5–2× atoms

  5. Fit and render

    A PyMOL script loads the chains, fits each structure onto the first, stacks them as states and exports animated.gif.

    PyMOLffmpeg

The reference structure is the first file: the first BLAST hit, or the first line of your list when you use -l. With a list, the order of its lines is also the order of the animation.

Two ways to animate the same structures

Both modes start from the same filtered set. They differ in which atoms are fitted and in what happens between one structure and the next. Below, the same adenylate kinase structures shown both ways.

Superposition default

Every structure is fitted onto the first with PyMOL super using all atoms of the chain, then shown for 10 frames before the next one. The motion jumps from one real conformation to the next. PyMOL runs headless, so you get the GIF directly.

Atoms
All polymer atoms
Fit
super, sequence-independent
Between states
None (10 frames per structure)
Needs
Open-source PyMOL

Structural alignment

Only the backbone is kept and fitted with PyMOL align. Then morph interpolates 30 frames between each consecutive pair, giving smooth continuous motion. The script writes the .pml file for you to run.

Atoms
Backbone: CA, C, N, O
Fit
align, sequence-guided
Between states
Linear morph, 30 frames
Needs

Usage

The tool runs on Linux with conda. It needs an internet connection for the Entrez, BLAST and PDB steps, and ffmpeg so that PyMOL can encode the GIF.

Install

git clone https://github.com/DonGazpachoWR/3D_protein_simulator.git
cd 3D_protein_simulator
conda env create -f environment.yml
conda activate estructural
sudo apt install ffmpeg -y

Full pipeline from a PDB code

python MDsimulator.py -id 5OTX -o results/5otx

From a curated list, smooth morph

python MDsimulator.py -l examples/4AKE/curated.txt \
    -o results/4ake -m structural_alignment
pymol results/4ake/molecular_dynamics_morph.pml

Several chains, fixed colour

python MDsimulator.py -id 3QGK -o results/3qgk \
    -ht 30 -c A,B,C -col green

What to keep in mind

The animation is only as meaningful as the structures and their order. These points cover most failed or misleading runs.

It is an illustration, not a trajectory

Linear interpolation moves every atom along a straight line, so intermediate frames can contain clashes or stretched bonds. Only the end points of each segment are experimental.

Order the structures yourself

Frames follow the BLAST ranking or your list, not a reaction coordinate. For a clean motion, list the structures from one end state to the other, for example apo to ligand-bound.

Choose a typical reference

The atom-count filter compares every file with the first. If that structure is a fragment or a large complex, most of the others are discarded. Check filtered_pdb.txt.

Watch the chain names

Many entries label chains inconsistently. The script maps label IDs to author IDs, but an empty or partial frame usually means the chain selection needs adjusting.

Start each list in a clean folder

The filter reads every file in pdbs/, so leftover structures from an earlier run end up in the animation. Delete them or use a new output directory.

Morphing needs a licensed PyMOL

The morph command is part of Incentive PyMOL. With open-source PyMOL, use superposition mode, which works without it.
